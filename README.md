# Weather Aggregator Service 🌤️ (Work in Progress)

Бэкенд-микросервис для агрегации и кэширования погодных данных из открытых источников (OpenWeather, WeatherAPI).

## Стек технологий
* **Платформа:** .NET 8 / C#
* **Фреймворк:** ASP.NET Core Web API
* **ORM:** Entity Framework Core
* **База данных:** SQLite (для локальной разработки) / PostgreSQL
